# Budget App
The budget app project is the second challenge given by freeCodeCamp.com on its python certification path.

## Description
The aim of the app is simply to track the transactions by the user. 
The deposit and withdrawal money from the balance is recorded by the program and later given as a receipts list (similar to a bank record
book). <br />
The program is also displaying the percentage spent (or withdrawal, in this terms) distribution on the chart. The percentage however, is 
rounded down to nearest possible 10.

## Additional Note: for the test program  
The trickiest part to get the code pass, as the requirement for freeCodeCamp.com, is the line alignment on the chart. Even a small difference won't make the code successfully passed. <br />
For the line alignment, I have to thanks several Github users who kindly shows the spacing between each string on the chart in their repositories. <br />
